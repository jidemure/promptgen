# Stop-motion creature prompt builder

A single-page tool that builds a text-to-video prompt: human hands craft a tiny animal from waste material with a hot glue gun, then the finished sculpture comes alive with an animation of your choice.

## Features
- Three fields: **Animal** (about 150 options), **Waste material** (about 130) and **Animation** (about 60, including many dances)
- Pick from filterable lists or type your own
- **Surprise me** randomizes all three
- **Copy prompt** copies the finished prompt to your clipboard
- Works on phones, supports light and dark mode, no dependencies

## Use
Open `index.html` in a browser, or host it with GitHub Pages:
Settings, Pages, Source: `main` branch, `/ (root)`.

## Customize
Edit the `animals`, `mats` and `anims` lists, or the prompt template `T`, near the top of the script in `index.html`.
